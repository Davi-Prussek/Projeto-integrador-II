# Projeto Integrador II

### Este repositório possui as atividades do tutorial de Django do professor Fábio Longo de Moura em projeto integrador II e as atividades do ano letivo do professor Kennedy Araújo.

# 

## NOTA:

> Para ter uma base de conhecimento de backend para entender o repositório e o seu conteúdo, você pode escolher ver o próprio tutorial de Django do professor Fábio Longo de Moura, onde você irá aprender a usar um pouco do framework. Caso deseje ir, clique [aqui.](https://github.com/ldmfabio/ProjetoIntegrador.git)

> Para ter uma base de conhecimento de frontend para entender o repositório e o seu conteúdo, você pode escolher ver o próprio tutorial de Vue.JS do professor Eduardo da Silva, onde você irá aprender a usar o framework,
caso deseje ir, clique [aqui.](https://eduardo-da-silva.github.io/desenvolvimento-web/)
